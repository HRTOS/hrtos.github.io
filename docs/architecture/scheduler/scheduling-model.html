调度模型 Scheduling Model

调度模型描述任务如何从就绪状态进入执行状态，以及系统在任务状态、 优先级或时间条件发生变化时，如何决定是否需要进行任务切换。 它连接任务管理、优先级规则、中断处理与上下文切换，是理解内核运行路径的关键。

Ready-State Management Priority-Based Decision Context Switching 8051 RTOS
01

调度模型定义

调度决策建立在任务状态和内核规则之上。

调度器并不是简单地在每次中断发生时重新选择任务。 系统需要先处理事件对任务状态的影响，再根据调度规则判断是否发生执行权转换。 事件可能使任务就绪、使当前任务阻塞或改变时间相关状态； 只有当执行条件和调度规则允许时，才会进入相应的任务切换路径。

调度决策 = f（就绪任务，优先级，调度模式，切换条件）

这是用于解释调度输入的概念模型，并非 HRTOS 内核中的实际函数或源代码表达式。 中断、超时和 IPC 等事件可能改变任务状态，但它们的处理路径及是否触发任务切换， 需要以具体内核实现为准。

INPUT / 01

任务状态

哪些任务已就绪、哪些任务正在运行，以及哪些任务因等待或其他条件暂时不能运行。

RULE / 02

调度规则

优先级、调度模式和时间片规则共同约束任务执行权的选择与交接。

ACTION / 03

执行状态转换

系统可能继续当前任务，也可能在满足切换条件后保存当前上下文并恢复另一个任务。

02

调度决策流程

从事件处理到执行权转换，区分状态更新与上下文切换。

概念性调度流程 Conceptual Execution Path
STEP 01 事件或调度条件出现 中断、超时、任务主动调用等
→
STEP 02 更新相关状态 就绪、阻塞、等待与时间状态
→
STEP 03 判断是否需要切换 结合优先级与调度规则
STEP 04A 继续当前任务 切换条件不成立时
↔
STEP 04B 保存与恢复上下文 切换条件成立时进入切换路径
→
STEP 05 任务继续执行 新执行状态开始运行

图示用于解释调度的逻辑过程，不代表所有事件都沿同一条固定代码路径执行。 中断处理、内核临界区、任务主动让出执行权和时钟节拍处理，可能具有不同的入口和切换条件。

03

任务状态与调度

任务的优先级决定相对执行权，任务状态决定它当前是否具备运行资格。

就绪任务

已具备运行条件、可以参与调度选择的任务。多个任务同时就绪时，执行顺序由调度规则决定。

当前运行任务

当前占用处理器执行的任务。发生事件后，系统可能继续执行它，也可能切换到其他任务。

阻塞或等待中的任务

等待时间、消息、同步条件或其他事件的任务，通常需要相应条件满足后才能重新参与调度。

空闲任务

当没有更高优先级的可运行任务时，系统可执行空闲任务。其具体运行方式取决于内核实现。

术语说明： “就绪集”“阻塞集”“超时集”可用于分析任务状态，但不应据此推断内核一定维护四个独立的物理队列或集合。 文档中的逻辑状态分类与实际数据结构应当分别描述。
04

调度行为与机制

不同机制解决不同问题，不应把它们视为互相排斥的调度类型。

PREEMPTION

抢占式调度

在符合调度条件时，更高优先级的就绪任务可以获得执行机会。 实际切换仍受内核临界区、中断状态及具体调度规则约束。

TIME SLICE

时间片调度

时间片机制用于限制特定任务连续占用处理器的时间。 是否轮转、哪些优先级参与轮转，以及时间片到期后的行为， 需要按照 HRTOS 的具体规则理解。

EVENT HANDLING

事件驱动与任务唤醒

中断、超时或通信事件可能改变任务状态并使任务重新就绪。 事件发生本身不意味着必然进行上下文切换。

REAL-TIME ANALYSIS

实时性分析

实时分析评估任务响应时间与截止期限之间的关系。 它需要结合执行时间、干扰、阻塞和系统开销，而不是单靠调度策略名称作出结论。

05

调度开销与响应时间

调度决策的成本也是任务时序分析的一部分。

任务响应时间不仅包括任务本身的执行时间，也可能受到更高优先级任务、中断处理、 资源等待和上下文切换等因素的影响。对于资源受限的 8051 系统， 保存与恢复寄存器、栈空间安排和中断控制路径尤其值得关注。

响应时间分析 = 执行时间 + 干扰 + 阻塞 + 相关系统开销

这是用于组织分析项目的概念表达式，不是适用于所有调度算法的完整数学公式。 进行正式计算时，需要根据调度策略定义各项的边界与计数方式，避免遗漏或重复计算开销。

分析原则： 测得的平均切换时间可以帮助评估性能，但不能直接代替最坏情况下的时间上界。 若要对截止期限作出保证，还需明确最坏情况执行时间、任务到达模式、阻塞上界、 中断干扰与测量或分析方法的适用范围。
