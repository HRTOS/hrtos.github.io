Time Control Module

时间控制

时间控制模块用于展示 HRTOS 中时间管理机制的核心功能。 涵盖 Tick 系统、延时机制、软件定时器、超时控制与调度时序等关键时间管理概念。

模块概述

时间控制是实时系统的核心基础，本模块用于描述 RTOS 中的时间管理机制， 包括 Tick 系统、延时机制、软件定时器、超时控制与调度时序。 通过时间管理模块解决任务调度和周期执行问题。

核心机制 Tick 系统驱动
关键特性 延时与阻塞管理
定时功能 软件定时器回调
调度联动 时间驱动任务切换

Module Introduction

模块介绍

时间控制模块的核心价值

时间控制模块用于展示 HRTOS 中时间管理机制的核心功能。 通过本模块的学习，可以深入理解 Tick 系统、延时机制、软件定时器、超时控制与调度时序等关键概念。 时间控制在实时系统中具有核心作用，直接影响任务调度和周期执行的准确性。

模块包含： Tick 系统 · 延时机制 · 软件定时器 · 调度时序
