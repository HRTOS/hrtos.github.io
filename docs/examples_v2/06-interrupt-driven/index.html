Interrupt Driven Module

中断驱动系统

中断驱动系统模块用于展示 HRTOS 中断响应与实时性管理的核心机制。 涵盖中断进入流程、嵌套中断控制、中断延迟分析以及中断与任务调度的协同机制。

模块概述

中断是实时系统中事件响应的入口，本模块用于描述中断从触发到ISR执行、 嵌套处理、上下文保存与恢复的完整流程，以及中断如何触发任务调度。

核心机制 中断响应流程
关键特性 优先级嵌套
实时分析 延迟测量
调度协同 中断触发切换
