Task Execution Module

任务执行

任务执行模块用于展示 HRTOS 中任务生命周期管理的核心机制。 涵盖任务创建、任务状态管理、上下文切换以及任务同步相关机制。

模块概述

任务是 RTOS 中的最小执行单元，本模块用于描述任务从创建到运行、 阻塞、切换与终止的完整生命周期与执行机制。

核心机制 任务生命周期管理
关键特性 状态转换与调度
同步机制 优先级继承
执行模型 上下文切换
