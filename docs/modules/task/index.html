Task Module 任务管理与执行上下文

Task 模块描述 HRTOS 中任务的组织与执行方式， 涵盖任务生命周期、状态模型、优先级管理与上下文切换。 从任务控制到 CPU 执行现场，这些机制共同构成系统任务运行的基础。

Execution Model

任务体系的三个层次

任务管理并不只是创建任务。任务状态决定任务当前所处的阶段， 优先级影响调度选择，而上下文切换负责衔接不同执行实体的运行现场。

LAYER 01

状态与生命周期

描述任务何时具备运行条件、何时等待事件，以及任务状态 如何随系统操作发生变化。

LAYER 02

优先级与调度

调度器根据系统配置、任务状态及优先级规则选择后续执行实体。 优先级规则与具体任务编号是不同概念。

LAYER 03

上下文与现场恢复

通过堆栈指针和上下文管理机制衔接执行现场， 使任务能够在获得 CPU 执行权时从正确的位置继续运行。
