调度器
Scheduler

调度器负责根据系统的调度规则选择后续执行的任务，并协调任务运行与上下文切换。 本模块围绕 优先级、任务调度策略、时间片机制与调度流程 组织相关文档，帮助理解 HRTOS 如何管理任务执行。

01 / Overview

调度器负责什么？

多任务系统中，多个任务可能同时处于可运行状态。 调度器根据系统定义的调度规则，决定哪个任务获得执行机会， 并与任务状态管理、时钟或事件触发机制以及上下文切换协同工作。

调度策略决定任务选择规则；上下文切换负责保存当前执行状态并恢复目标任务状态。 两者相互配合，但承担的是不同职责。

Execution Model

从调度条件到任务运行

调度并不只是“选择最高优先级任务”这一条规则。 具体行为还取决于任务是否就绪、调度触发条件、 当前执行上下文以及系统配置。

调度条件出现 时钟、任务状态变化或内核调度请求
↓
执行调度规则 依据当前系统策略选择目标任务
↓
必要时切换上下文 保存当前状态并恢复目标任务状态

03

调度与上下文切换

任务选择和任务切换是紧密相关、但职责不同的两个过程。

调度器确定目标任务后，系统还需要通过相应执行路径处理任务现场。 在 8051 平台上，相关工作可能涉及寄存器保存与恢复、栈指针管理、 中断返回路径以及编译器调用约定。具体步骤应以 HRTOS 的调度流程和内核实现为准。
