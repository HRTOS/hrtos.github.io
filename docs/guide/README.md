# HRTOS 开发者文档

## 概述

本文档面向 HRTOS 内核开发者，介绍系统架构、核心机制、内部实现以及性能测试结果。

HRTOS（High-performance Real-Time Operating System）是一款面向 8051 微控制器优化的轻量级实时操作系统，专注于有限资源环境下的实时调度、高效任务切换以及低内存占用。

本文档主要用于：

- 理解 HRTOS 内核设计
- 分析核心模块实现
- 调试系统运行问题
- 进行功能扩展
- 评估系统实时性能

对于应用开发和 API 使用，请参考用户开发文档。

# 系统特性

- **目标平台**：8051 微控制器
- **编译环境**：Keil C51
- **任务模型**：标准任务 + 高速任务
- **调度方式**：基于优先级的抢占式调度
- **时间管理**：Timer0 系统 Tick
- **IPC 支持**：
  - 事件
  - 消息队列
  - 信号量
  - 互斥锁
  - 邮箱
- **内存管理**：静态分配，资源状态统一管理

# 快速参考

## 关键数据结构

- `OS_TCB`：任务控制结构
- `OS_RESOURCE`：统一资源对象
- 消息队列结构
- 调度状态变量

## 关键配置

- `OS_PROCESS_MAX`：标准任务数量
- `OS_FAST_TASK_MAX`：高速任务数量
- `OS_RESOURCE_MAX`：IPC 资源数量
- `OS_MSGQ_MAX`：消息队列数量

## 内存布局

示例配置：

- 系统栈区域：0x35 - 0x39
- 中断栈区域：0x3A - 0x41
- 用户栈区域：0x42 - 0x7F
- XDATA 全局区域：0x0200 - 0x03FF

# 性能测试

## 测试环境

测试平台：

- MCU：STC12C5A60S2
- 架构：8051
- 编译器：Keil C51
- 系统时钟：11.0592MHz
- 工作模式：12T模式

## 实时性能测试

| 测试项目 | 测试结果 |
| --- | --- |
| 上电启动时间（Power On → hrtos_main） | 346.6493 ms |
| 内核启动延迟（hrtos_main → 首任务运行） | 11.094458 ms |
| 普通任务切换时间 | 398.708 μs |
| 高速任务切换时间 | 294.292 μs |
| 高速任务切换优化效果 | 约 26.2% |
| 系统 Tick 周期(OS_TIME_T0设9162) | 约 10.000 ms |
| 毫秒延时精度（os_delay_ms(1)） | 1.0005 ms |
| 定时器中断响应时间 | 12.208 μs |
| 事件唤醒延迟 | 835.458 μs |
| 阻塞切换至任务唤醒运行总耗时 | 1.289708 ms |

## 性能分析

测试结果表明：

- 系统 Tick 周期稳定在约 10ms
- 毫秒级延时具有较高精度
- 高速任务通过优化上下文切换流程降低切换时间
- 中断响应保持在微秒级
- IPC 唤醒路径具有较低延迟

高速任务切换相比普通任务切换减少约 26.2% 的上下文处理时间，适用于对响应速度要求较高的任务场景。

# 系统要求

## 最低硬件要求

- 标准 8051 内核 MCU
- 片外 RAM ≥ 1KB
- Flash ≥ 8KB

## 推荐硬件配置

- STC12 / STC8 系列
- RAM ≥ 2KB
- Flash ≥ 16KB

## 开发环境

- Keil C51（主要支持环境）
