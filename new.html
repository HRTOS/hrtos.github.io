05 / QUICK START

从一个任务，
理解实时系统。

下面的示例展示两个独立任务的基本组织方式。通过任务入口与延时调用，可以直观理解 HRTOS 应用程序的基本结构。具体接口、参数和工程配置请以对应版本的 API 文档为准。

dual_task_demo.c
/* HRTOS — Dual Task Example */
#include "hrtos.h"

#define FAST_TASK_ID   1
#define SLOW_TASK_ID   2

static void fast_task(void)
{
    while (1)
    {
        LED_FAST = !LED_FAST;
        os_delay(2);
    }
}

static void slow_task(void)
{
    while (1)
    {
        LED_SLOW = !LED_SLOW;
        os_delay(25);
    }
}

void hrtos_main(void)
{
    os_task_create((unsigned int)fast_task, FAST_TASK_ID, 7, 5);
    os_task_create((unsigned int)slow_task, SLOW_TASK_ID, 3, 5);
}
